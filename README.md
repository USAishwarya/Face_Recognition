# Real-Time Face Recognition using CNN

This project implements a real-time face recognition system using Convolutional Neural Networks (CNNs) with TensorFlow/Keras and OpenCV. It includes model training, prediction, and real-time face recognition via webcam, enhanced with a simple GUI.

---

## 📌 Features

- Face dataset creation using OpenCV
- CNN model built from scratch for facial classification
- Model training with early stopping and validation
- Real-time webcam-based recognition
- User-friendly GUI to trigger the recognition

---

## 🛠️ Tech Stack

- Python
- OpenCV
- TensorFlow / Keras
- NumPy
- Tkinter (for GUI)
